Privacidad · Lector

Proyecto de Alejandro Pico. Actualizado el 15 de octubre de 2026.

Lector abre los libros que eliges y guarda preferencias, posiciones, notas, diccionarios y audios en el almacenamiento local de tu navegador o aplicación. No incorpora publicidad, analítica, identificación publicitaria ni un servidor del proyecto al que se envíen tus libros.

Servicios opcionales

Las voces del sistema las proporciona el motor de tu dispositivo o navegador. Algunas necesitan conexión y procesan texto con su propio proveedor. Si configuras una API de voz o inteligencia artificial, se enviará el fragmento solicitado al proveedor elegido. Puede aplicar sus condiciones y cobrar por uso. Las claves se mantienen durante la sesión.

La sincronización se inicia expresamente. Envía al destino que configures las categorías que revises y confirmes: posiciones, notas/subrayados y, opcionalmente, preferencias. No sube los archivos de libros ni los audios. OneDrive usa la carpeta de la aplicación y está disponible en la versión web con un registro Microsoft propio. WebDAV usa tu servidor y puede necesitar permitir el origen de la aplicación.

Archivos y permisos

La selección de una carpeta permite enumerar sus nombres y referencias; su contenido se lee al abrir un libro o solicitar metadatos o portadas. Las portadas visibles se cargan automáticamente por defecto, también las incrustadas, con permisos ya concedidos. Puedes desactivarlo en Ajustes → Biblioteca. Obtener una portada incrustada puede descargar el ebook correspondiente desde la nube. Las rutas escritas como referencia se conservan localmente. Si el archivo está en un proveedor de nube, este puede descargarlo al abrirlo. Los originales no se editan. Las exportaciones se guardan solamente tras una acción del usuario y una elección de destino.

La lectura en voz alta usa salida de audio; no necesita grabar el micrófono, acceder a contactos ni conocer tu ubicación. Android muestra los controles de la lectura activa mediante una notificación de reproducción.

Conservación y eliminación

Puedes quitar libros, notas, paquetes y otros recursos desde sus controles. Borrar todos los datos del sitio o de la aplicación elimina sus datos locales; no borra los libros originales ni los datos que hayas guardado en otros servicios. Las versiones web e instaladas tienen almacenamiento independiente. No existe una copia automática del proyecto de esos datos.

Privacy

Lector is a project by Alejandro Pico. It stores selected books and reading data locally, with no advertising, analytics or publisher-operated book upload server. Device/browser speech engines may process text online under their own terms. Optional voice/AI APIs receive only the requested text; keys last for the session. Voluntary synchronization sends reviewed reading data to your chosen service, not ebook or audio files. Cloud file providers may download a selected file when opened. Visible covers load automatically by default with existing permissions; extracting embedded covers may download the ebook from its cloud provider. This can be disabled in Settings → Library. Folder path labels stay local. Original files are not edited, exports require an explicit action, and no microphone, contacts or location are required. Remove local data through the app or operating system. Web and installed apps have separate storage. Contact the project through the issue link above. Updated 15 October 2026.
