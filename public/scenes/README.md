Fondos originales generados con la herramienta integrada `image_gen` (sin API del usuario), el 15 de octubre de 2026. ## Prompts finales

### home.webp

Use case: photorealistic-natural. Asset type: full-screen background for a physical-book reading application. Create ONE ultra-realistic 3:2 landscape photograph of a beautiful empty honey oak reading table seen directly from above, camera perfectly perpendicular, wood grain, finely worn natural satin finish, warm soft daylight falling from upper left with very subtle leaf shadow only along far outer edges. The empty wooden surface fills the entire frame, no table edges, no horizon. Center 90% of image entirely clear uninterrupted oak, reserved for a large interactive book rendered separately in code. Authentic fine pores and grain, sophisticated calm home library atmosphere. No book, paper, objects, lettering, border, collage or watermark. Save the generated project asset.
