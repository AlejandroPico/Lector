# Fuentes personales del proyecto

Coloca aquí archivos `.woff2`, `.woff`, `.ttf` u `.otf` (extensión en minúsculas), también en subcarpetas. Se detectan al iniciar el desarrollo o compilar y se ofrecen en Tipografía y página. El nombre de archivo sirve como nombre visible; cada archivo tiene su propia familia. Añade la licencia o atribución correspondiente al archivo si se distribuye con el proyecto.

Para uso personal sin modificar el repositorio, utiliza «Añadir fuente» en el lector: se guarda dentro del navegador, no en Descargas. Una web publicada no puede inspeccionar carpetas privadas sin selección del usuario.
